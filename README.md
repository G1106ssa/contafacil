# SisContábil

Sistema contábil web (escrituração: plano de contas, lotes, lançamentos, lançamentos automáticos,
importação por Excel, Diário, Razão e Balancete). Usa o mesmo Supabase e o mesmo login do SisFiscal,
numa área própria do banco (schema `contabil`).

Publicado em https://g1106ssa.github.io/contafacil/ — substitui o antigo ContaFácil (o código dele
continua no histórico deste repositório).

O código-fonte de trabalho, o schema do banco e os testes ficam na pasta do projeto SisContábil.
